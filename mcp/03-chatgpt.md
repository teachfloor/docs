# ChatGPT

**Coming soon.** The Teachfloor app has been submitted to the ChatGPT apps directory and is waiting to be published.

## What Will Change

Once the listing is live, you will add Teachfloor from the apps directory: open the app, approve the access on a Teachfloor consent screen, and the tools become available in the conversation. Nothing will need to be set up in Teachfloor first — no application to register, no key to paste.

This page will carry the direct link when it exists.

## In the Meantime

The server is already running, and it is not specific to any one assistant — it speaks the [Model Context Protocol](https://modelcontextprotocol.io), so anything that supports remote MCP servers can connect to it today. See [Custom Clients](./custom) for connecting one, or for calling the server directly from a script.

The endpoint, the authentication and the tools are the same however you connect — see [Getting Started](../getting-started). Only the way you add it differs.
